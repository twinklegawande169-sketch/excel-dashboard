# Interactive Excel Sales Dashboard

## Project overview

This project uses Excel to turn retail sales data into an interactive dashboard. The dashboard contains PivotTables, charts, KPI cards, and slicers.

## Dataset source

Synthetic retail sales dataset created for dashboard practice. It contains 750 fictional sales records and no real personal or company information.

## Questions answered

1. What are total sales, total profit, and total quantity sold?
2. Which category generates the most sales?
3. How do sales change over time?
4. Which products and regions perform best?

## Workbook contents

- `Retail Data` - cleaned source data stored as an Excel Table
- `PivotTables` - summaries used by charts and KPI cards
- `Dashboard` - interactive charts, KPI cards, Region slicer, and Category slicer

## How to use the dashboard

Open the Excel workbook and go to the `Dashboard` sheet. Use the Region and Category slicers to filter the KPI cards and charts. Use the clear-filter icon on a slicer to return to the complete dataset.
