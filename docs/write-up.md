# Dashboard Write-Up

## Purpose

This dashboard summarises retail sales performance for a non-technical user. It provides a clear view of sales, profit, quantity, category performance, monthly trends, and top products.

## How to use the dashboard

Use the Region and Category slicers on the Dashboard sheet to filter the information. The KPI cards and all charts update automatically because the slicers are connected to the PivotTables.

## Key insights

- Total sales were $589,545.70.
- Total profit was $204,397.09.
- Total quantity sold was 3,253 units.
- Technology was the highest-sales category.
- Laptop was the top-selling product.
- West was the highest-sales region.

## Future improvement

With more time, I would add a date Timeline slicer and a profit-margin chart to make the dashboard more detailed.
