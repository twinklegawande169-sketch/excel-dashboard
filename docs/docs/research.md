# Research

## PivotTables

A PivotTable is an Excel feature that summarises large data tables without changing the original data. It can group records by fields such as category, region, or month and calculate totals, averages, or counts.

Source: [Microsoft Support - Create a PivotTable](https://support.microsoft.com/en-US/Excel/get-started/create-a-pivottable-to-analyze-worksheet-data)

## Chart selection

A bar or column chart is useful for comparing categories or products. A line chart is useful for showing changes over time. This project uses a column chart for categories, a line chart for monthly sales, and a bar chart for top products.

Source: [Microsoft Support - Available chart types](https://support.microsoft.com/en-us/excel/available-chart-types-in-office)

## Dashboard design

A dashboard should use a clear title, readable labels, aligned charts, a small number of colours, and limited clutter. KPI cards should be placed at the top because they give users a quick summary.

## Slicers

Slicers make a dashboard interactive by allowing users to filter data with visible buttons. In this dashboard, the Region and Category slicers update all connected KPI cards and charts.

Source: [Microsoft Support - Use slicers](https://support.microsoft.com/en-us/excel/get-started/use-slicers-to-filter-data)
